## 🚀 Негізгі мүмкіндіктер (Features)

- **97+ Дайын AI нұсқаулықтары мен кодтар:**
  - 🤖 Жүйелер мен Агенттер (Systems & Multi-Agent Swarms)
  - 🛠️ Баптау нұсқаулықтары (Setup Guides & MCP)
  - 📖 Плейбуктар (Playbooks & Workflows)
  - 💡 Промпттар (Mega Prompts & Codes)
  - 🎬 Видео және Монтаж (Automated Reels & Shorts)
  - 🎨 Визуал мен Карусель (Visuals, Midjourney & SMM)
- **Швейцариялық минималистік дизайн және үйлесімді типографика:**
  - Жылы қағаз реңктері (`#f0eee6`, `#faf9f3`), таза қаріптер (`Plus Jakarta Sans` + `Inter` + `JetBrains Mono`), толық қазақша кириллица қолдауы.
- **Лезде сүзу және санағыштар:**
  - Әр санат бойынша нақты материал санын көрсететін динамикалық сүзгілер.
- **Жүйрік іздеу жүйесі (Instant Search):**
  - Атауы, сипаттамасы немесе тегтері бойынша миллисекунд ішінде іздеу. `Ctrl + K` немесе `/` пернесі арқылы жылдам шақыру.
- **Интерактивті модальды оқу терезесі (Guide Reader):**
  - Қадам-қадамдық нұсқаулықтар, кеңестер және дайын промпттарды бір батырмамен буферге көшіру (`Көшіріп алу` -> `Көшірілді! ✓`).
- **Бейімделгіш интерфейс (Fully Responsive & Accessible):**
  - Смартфон, планшет және компьютер экрандарында мінсіз жұмыс істейді.

## 📂 Жоба құрылымы (Project Structure)

```
wnk-education/
├── index.html        # Семантикалық HTML5 құрылымы
├── style.css         # Швейцариялық редакциялық дизайн жүйесі (CSS токендері)
├── app.js            # Іздеу, сүзу және модальды терезе логикасы
├── data.js           # 97 қазақша бейімделген толыққанды AI ресурстар базасы
└── README.md         # Жоба құжаттамасы
```

## 💻 Жергілікті іске қосу (Local Setup)

Ешқандай күрделі кітапхана немесе орнатуды қажет етпейді:

1. Репозиторийді жүктеп алыңыз:
   ```bash
   git clone https://github.com/artishertekuly-bit/wnk-education.git
   cd wnk-education
   ```
2. `index.html` файлын кез келген браузерде ашыңыз немесе жергілікті сервер іске қосыңыз:
   ```bash
   npx serve .
   ```
