## 🎮 Жаңа: Интеллектуалды Геймификация модулі (Realtime Gamification)

Платформаға тіркелген қолданушылар бір-бірімен немесе **WNK AI Ұстазбен** нақты уақытта білім жарысына түсе алады:

### 1. Ойын түрлері мен механикасы
- ⚓ **Морской бой (Теңіз шайқасы, 10x10):**
  - Ойыншы нысанаға оқ көздейді -> Экранға сұрақ шығады.
  - Таймер: `easy`/`medium` сұрақтарға 30 сек, `hard` пен мәтіндік сұрақтарға 45 сек.
  - Дұрыс жауап берсе: оқ атылады (`hit` немесе `miss`).
  - Қате жауап берсе немесе таймер таусылса: оқ атылмайды, кезек қарсыласқа өтеді.
  - **Радар бонусы:** Қатарынан 3 дұрыс жауап берген ойыншы `hard` сұраққа жауап беріп, қарсыластың 3x3 аумағын сканерлейтін "Радар" бонусын іске қосады!
- 🏁 **Шашки (8x8):**
  - Жай жүріс үшін — `easy` сұрақ (30с).
  - Қарсыластың тасын жеу (алу) үшін — `medium` сұрақ (30с).
  - Дамкаға шығу немесе дамкамен жүру үшін — `hard` сұрақ (45с).
  - Дұрыс жауапта ғана жүріс орындалады, қате жауапта тас орнында қалып, кезек қарсыласқа ауысады.

### 2. AI Интеграциясы және Model Fallback тізбегі
Сервер 25 сұрақты таңдалған тақырып бойынша Google Gemini AI арқылы генерациялайды. Егер бір модельдің лимиті толса (429 Rate Limit қатесі), жүйе автоматты түрде келесі модельге ауысады:
1. `gemini-2.5-flash-lite`
2. `gemini-2.5-flash`
3. `gemini-3.6-flash`
4. `gemini-3.8-flash`
*(Сонымен қатар желіден тыс кезде 100% үздіксіз жұмыс істейтін офлайн академиялық қоры бар).*

### 3. Тақырыпқа бейімделу критерийлері:
- **Математика:** Жай теория емес, нақты есептеуді, логикалық амалдарды және теңдеулерді шешуді талап ететін есептер.
- **Оқу сауаттылығы:** Әр сұрақта (`context_text` өрісінде) 3-5 сөйлемнен тұратын мәтіндік үзінді беріледі және негізгі ойды табуға бағытталады.
- **Жаратылыстану ғылымдары (Физика, Химия, Информатика, Биология):** Нақты формулалар ($F = ma$, $E = mc^2$, $I = U/R$), заңдылықтар және әлемдік пен қазақстандық ғалымдар (Әл-Фараби, Ньютон, Эйнштейн, Менделеев, Тьюринг, Сәтбаев) қатысады.

### 4. Реалтайм Архитектурасы (WebSockets + In-Memory State)
- Дерекқорға (DB) салмақ салмау үшін барлық бөлмелердің күйі Render серверінің жедел жадында (RAM) сақталады және WebSocket (`ws://` / `wss://`) арқылы синхрондалады.
- **Анти-чит қауіпсіздігі:** Қарсыластың кемелері мен сұрақтардың дұрыс жауаптары ешқашан қарсыластың браузеріне жіберілмейді, тек серверде тексеріледі.

## 📂 Жоба құрылымы (Project Structure)

```
wnk-education/
├── index.html            # Семантикалық HTML5 құрылымы + Арена + Модальдар
├── style.css             # Дизайн токендері және Геймификация стильдері
├── app.js                # Ресурстар, сүзгілер, іздеу және Supabase Auth
├── gaming.js             # Геймификация фронтенді: WS клиент, аудио, тақталар
├── server.js             # Node.js + Express + WebSocket реалтайм сервері
├── game-engine.js        # Морской бой & Шашки ережелері мен бот логикасы
├── gemini-service.js     # Gemini AI 4-деңгейлі Model Fallback сервисі
├── render.yaml           # Render.com авто-деплой конфигурациясы
├── package.json          # Node.js тәуелділіктері (express, ws, cors, dotenv)
└── data.js               # 97 қазақша бейімделген толыққанды AI ресурстар базасы
```

## 💻 Жергілікті іске қосу (Local Setup)

1. Репозиторийді жүктеп алыңыз:
   ```bash
   git clone https://github.com/artishertekuly-bit/wnk-education.git
   cd wnk-education
   ```

2. Тәуелділіктерді орнатыңыз және іске қосыңыз:
   ```bash
   npm install
   npm start
   ```

3. Браузерде ашыңыз: `http://localhost:3000`
